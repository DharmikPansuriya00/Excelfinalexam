# Superstore Sales Performance Dashboard

## 📊 Project Overview
The **Superstore Sales Performance Dashboard** is an interactive Excel-based business intelligence solution designed to analyze sales, profit, discounts, categories, regions, products, and yearly trends.

## 🎯 Objectives
- Analyze overall sales and profitability
- Identify top-performing categories, products, and states
- Monitor discount impact on profit
- Compare year-wise performance
- Build an interactive dashboard using Excel

## 🛠 Tools & Features Used
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Conditional Formatting
- GETPIVOTDATA
- XLOOKUP
- VLOOKUP
- HLOOKUP
- INDEX + MATCH
- Data Validation

## 📈 Key KPIs
- Total Sales: $2,297,200
- Total Profit: $286,397
- Average Discount: 15.62%
